ARKHE-ZERO

Protocolo local-first para sellar y verificar autoría humano-IA con SHA-256, JSON canónico RFC 8785 y firmas híbridas Ed25519 + ML-DSA-65 (NIST FIPS 204).

Quickstart — 30 segundos
git clone https://github.com/SYCRO-VALDOVINOS/ARKHE-ZERO.git
npm install
node scripts/generate-and-verify-vectors.mjs --verify-only
node scripts/verify-vc.mjs && node scripts/verify-audit-report.mjs
